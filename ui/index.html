Where to find your results

In the career-ops folder (the one you extracted from the ZIP):

  • Evaluation report: the reports folder, the newest file, named {number}-{company}-{date}.md. It opens in any text editor.
  • Tailored CV (PDF): the output folder (it may be inside a sub-folder for that application).
  • Application list: data/applications.md.

Claude Code also prints the exact paths at the end of its answer, under Results. Copy one into Finder (Cmd+Shift+G) or the Explorer address bar.
